Download and extract the PR artifact, then copy `aic-tactics-description-preview-0.0.1.zip` into your test installation's `ucp/plugins` folder without unpacking that inner ZIP.
Open the installation in UCP GUI, select **AIC Tactics (description preview)** in the installed extensions list and open its description; change the GUI language to check the translated text.
This ZIP tests the descriptions only: it adds no AI behavior and does not need to be enabled or launched in-game.
