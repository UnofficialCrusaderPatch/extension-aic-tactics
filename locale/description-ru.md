Добавляет в AIC настройки набора войск и выбора целей. Без новых настроек поведение ИИ сохраняется.

### Набор войск

- `RecruitPolicy`: `Native` (по умолчанию) сохраняет прежний набор. `WeightedRoles` распределяет его между обороной, набегами, основной армией и вылазками.
- `RecruitProbSortieDefault`, `RecruitProbSortieWeak`, `RecruitProbSortieStrong`: веса вылазок для обычного, слабого и сильного состояния ИИ. Целые числа **0–100**, по умолчанию **0**. Вместе с прежними весами обороны, набегов и атаки каждый уровень должен давать **100**. Требуется `WeightedRoles`; списки войск, интервалы и квоты сохраняются.
- `RecruitConditions`: до **8** упорядоченных правил, по умолчанию пусто. Первое подходящее правило заменяет веса уровня силы. Каждому нужны `When` и четыре веса с суммой 100: `Defense`, `Raid`, `Attack`, `Sortie`. Требуется `WeightedRoles`.

В `When` доступны `Strength` (`Default`, `Weak`, `Strong`), `HomeUnderThreat` (база под угрозой), `AttackActive` (идёт атака), `DefenseIncomplete` (оборона не укомплектована), `EquipmentSurplus` (избыток снаряжения). Все указанные условия должны совпасть; `true` требует выполнения условия, `false` — его отсутствия. Пустой `When` подходит всегда.

### Цели атаки

`AttackTargetPolicy`:

- `Inherit` (по умолчанию): По существующему `TargetChoice`.
- `LowestPopulation`: Меньше всего мирных жителей.
- `FewestTroops`: Меньше всего военных единиц.
- `LowestCombatPower`: Наименьшая оценочная военная сила, без учёта расстояния.
- `Random`: Случайный допустимый противник, с равными шансами для всех.
- `LastAggressor`: Последний нападавший, отвечающий условиям для ответного удара.

`AttackTargetCommitment`:

- `Default`: для новых правил — `PerAttack`; с `Inherit` — прежнее поведение.
- `PerAttack`: сохранять цель на протяжении всей атаки.
- `UntilDefeated`: сохранять цель между атаками, пока противник остаётся допустимым.

Частичное обновление сохраняет пропущенные значения. Возврат к прежнему поведению: `RecruitPolicy: Native`, `AttackTargetPolicy: Inherit`, `AttackTargetCommitment: Default`. Прежние веса вылазок и правила сохраняются неактивными; не указывайте их при переходе на `Native`.
