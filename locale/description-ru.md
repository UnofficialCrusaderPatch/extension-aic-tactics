Настройте в AIC набор войск, подготовку волн, цели атак и набеги ИИ. Без новых настроек прежнее поведение сохраняется.

### Набор войск

- `RecruitPolicy`: `Native` (по умолчанию) сохраняет прежний набор. `WeightedRoles` распределяет его между обороной, набегами, основной армией и вылазками.
- `RecruitProbSortieDefault`, `RecruitProbSortieWeak`, `RecruitProbSortieStrong`: веса вылазок для обычного, слабого и сильного состояния ИИ. Целые числа **0–100**, по умолчанию **0**. Вместе с прежними весами обороны, набегов и атаки каждый уровень должен давать **100**. Требуется `WeightedRoles`; списки войск, интервалы и квоты сохраняются.
- `RecruitConditions`: до **8** упорядоченных правил, по умолчанию пусто. Первое подходящее правило заменяет веса уровня силы. Каждому нужны `When` и четыре веса с суммой 100: `Defense`, `Raid`, `Attack`, `Sortie`. Требуется `WeightedRoles`.
- `DefRecruitComposition`: `Native` (по умолчанию) сохраняет прежнее поведение. `PreserveSlots` резервирует долю каждой записи `DefUnit1..8`; повторные записи увеличивают долю этого типа. При нехватке снаряжения места остаются свободными. Требуется `WeightedRoles`.
- `RecruitInitialDefenseMonths`: **0–30** месяцев, по умолчанию **6**. В этот период набор рейдеров и основной армии откладывается, пока оборона не укомплектована. Войска для вылазок набирать можно; нулевой вес не меняется. **0** отключает ожидание. Требуется `WeightedRoles`.

В `When` доступны `Strength` (`Default`, `Weak`, `Strong`), `HomeUnderThreat` (база под угрозой), `AttackActive` (идёт атака), `DefenseIncomplete` (оборона не укомплектована), `EquipmentSurplus` (избыток снаряжения). Все указанные условия должны совпасть; `true` требует выполнения условия, `false` — его отсутствия. Пустой `When` подходит всегда.

### Цели атаки

`AttackTargetPolicy`:

- `Inherit` (по умолчанию): По существующему `TargetChoice`.
- `LowestPopulation`: Меньше всего мирных жителей.
- `FewestTroops`: Меньше всего военных единиц.
- `LowestCombatPower`: Наименьшая оценочная военная сила, без учёта расстояния.
- `Random`: Случайный допустимый противник, с равными шансами для всех.
- `LastAggressor`: Последний нападавший, отвечающий условиям для ответного удара.

`AttackTargetCommitment`:

- `Default`: `PerAttack` для новых правил или `DuringAttack`; иначе прежнее поведение.
- `PerAttack`: сохранять цель на протяжении всей атаки.
- `UntilDefeated`: сохранять цель между атаками, пока противник остаётся допустимым.

### Подготовка и ответные атаки

- `AttackPreparation`: `Native` (по умолчанию) или `DuringAttack` — набирать следующую волну у замка во время текущей атаки. Лимиты войск и рост волн сохраняются.
- `AttackActivation`: `Immediate` (по умолчанию) или `AfterProvocation` — начинать атаки и набеги только после достаточно серьёзного нападения. Оборонительные вылазки доступны всегда.
- `ProvocationRules`: пороги ответной атаки. По умолчанию: `ThreatPower` **100**, `CombatTicks` **200**, `LossPower` **100**, `WindowTicks` **800**. Достаточны затяжные бои у цитадели или значительные потери войск; урон лорду учитывается сразу. Указывайте все четыре значения. **800 тиков = один игровой месяц**.

### Набеги

- `RaidTargetPolicy`: `Native` (по умолчанию), `NearestReachable` — ближайшие доступные здания, `Opportunistic` — выбор по расстоянию, приоритету и опасности.
- `RaidGroupCount`: **1–4**, по умолчанию **1**. Делит имеющиеся войска для набегов, не увеличивая их число.
- `RaidMinGroupSize`: **1–256**, по умолчанию **4**. Меньшие группы ждут или объединяются.
- `RaidFocus`: `Any` (по умолчанию), `Food` (еда), `Industry` (производство), `HighValue` (стоимость восстановления). Требует `Opportunistic`.
- `RaidRiskTolerance`: `Low`, `Medium` (по умолчанию), `High` — допустимая опасность от ближайших вражеских войск и укреплений.
- `RaidEnemyScope`: `PrimeTarget` (по умолчанию) или `AnyEnemy`. Цель основной армии не меняется.

Эти пять настроек требуют новой `RaidTargetPolicy`. `RaidUnitsBase`, `RaidUnitsRandom`, `RaidUnit1..8` и `RaidRetargetDelay` сохраняют действие. Возврат к исходному поведению: `AttackPreparation: Native`, `AttackActivation: Immediate`, `RaidTargetPolicy: Native`.
